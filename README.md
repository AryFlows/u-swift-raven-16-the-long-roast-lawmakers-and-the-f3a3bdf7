One satirical sentence (170 characters, gate 1–320) roasting lawmakers who would regulate AI but cannot convert a file to PDF.

> The senator who wrote the 400-page AI Safety Act still emails his staff a Word file named FINAL_FINAL.docx and asks them to 'make it a PDF' — by which he means rename it.

## Run

```sh
node main.ts
```

Writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).

## Gate

The program guards the gate itself: the entry must be 1–320 characters, a
single line, and not only whitespace — otherwise it exits with an error
before writing anything.

## Why this line

The judge weighs the turn first: the senator's authority is a 400-page AI
Safety Act, and the undercut lands on the last few words — his idea of
"making it a PDF" is renaming the file. `FINAL_FINAL.docx` is a specific,
recognisable detail instead of a worn tech-illiteracy cliché, and the joke
stays aimed at the lawmaker and the rules he writes.
